# Путь Героя

Текстовое приключение для телефона: выбираешь героя или героиню, вводишь имя и проходишь историю, принимая решения.

## Как устроено

Это **PWA** — веб‑приложение, которое ставится на телефон как обычное приложение (иконка на рабочем столе, полный экран, работает без интернета). Без сборки и без зависимостей: обычные HTML/CSS/JS.

```
put-geroya/
├── index.html            экраны: титул, создание героя, сюжет, настройки
├── story/story.js        ВЕСЬ СЮЖЕТ — единственный файл, который правится при написании истории
├── js/engine.js          движок: состояние, флаги, условия, переходы, сохранения
├── js/battle.js          бой в реальном времени (canvas): волки, меч, крестовина
├── js/text.js            подстановки: {name}, {пошёл|пошла}, подсветка «реплик»
├── js/share.js           «Поделиться» (системное меню телефона / копирование ссылки)
├── js/app.js             интерфейс
├── css/style.css
├── sw.js                 офлайн‑кэш (меняй VERSION при каждом обновлении!)
├── manifest.webmanifest  имя, иконка, полноэкранный режим
└── icons/
```

## Как делиться с друзьями (без сторов)

1. **Ссылка (основной способ).** Выкладываем папку на бесплатный хостинг — GitHub Pages, Netlify или Cloudflare Pages. Друг открывает ссылку в Chrome на Android → «Установить на телефон» (или меню ⋮ → «Добавить на главный экран»). На iPhone: Safari → «Поделиться» → «На экран „Домой“». Обновления приходят сами — достаточно перезалить файлы.
2. **Кнопки внутри игры.** «Поделиться игрой» на титуле и «Поделиться концовкой» в финале открывают системное меню (Telegram, WhatsApp и т.д.) с текстом и ссылкой.
3. **APK‑файл (по желанию, позже).** Ту же папку можно обернуть в Android‑приложение через Capacitor и отправить `.apk` в Telegram. Минусы: другу нужно разрешить установку из неизвестных источников, а обновления — вручную. Поэтому сначала ссылка.

Сохранение можно перенести на другой телефон: Настройки → «Скопировать сохранение» / «Вставить сохранение».

## Как писать сюжет

Формат сцен описан в шапке `story/story.js`. Главное:

- `{name}` — имя героя;
- `{пошёл|пошла}` — форма для героя | для героини;
- `choices` с `to` — куда ведёт выбор; `set` / `add` — флаги и счётчики; `if` — условие показа;
- `ending` — сцена‑финал (концовки копятся и показываются как «открыто 2/5»).

## Бой

Вид сверху. Крестовина ▲◀▶▼ — бег и уклонение (держишь — бежишь), 🗡️ — удар (меч сам доворачивает к ближнему волку), 🧪 — зелье (+40 здоровья). Волк перед прыжком приседает, под ним загорается красный круг и «!» — в этот момент надо уйти в сторону. С компьютера: стрелки/WASD, пробел, Q.

Сложность — ответ королеве: «уничтожу» = 4 волка, сильные и быстрые; «договориться» = 3; «мир» = 2 медленных + зелье в подарок. Цифры — в начале `js/battle.js` (`DIFF`).

## Запуск на компьютере

```bash
cd put-geroya && python3 -m http.server 8765
```

Открыть http://localhost:8765. Чтобы открыть с телефона в той же Wi‑Fi сети — http://IP‑компьютера:8765 (офлайн‑режим и установка там не заработают — для этого нужен https, то есть хостинг).
