# Путь Героя

Пиксельная top-down RPG в стиле Guardian Tales: герой или героиня из светлого королевства Люминос идёт в тёмную империю Нокт. Три пути — Надежды, Власти и Ненависти — и концовки, которые помнят прошлые прохождения.

Играть: https://volik1987.github.io/put-geroya/ — на телефоне можно «Добавить на экран „Домой“».

## Управление

WASD / стрелки — движение · Пробел / клик — атака · E — говорить · Q — бутылка с водой · Enter — дальше · Esc — пауза. На телефоне — экранный джойстик и кнопки.

## Как устроено

Без сборки и зависимостей: canvas 1280×720, тайлы 64×64, аниме-портреты 256×256.

```
index.html            сцена, диалог, меню, экраны концовки, «Ошибки 888» и достижений
game.js               движок: карты, бой, ИИ врагов, мини-игры, лабиринт, сохранения
dialogues.js          ВСЕ ТЕКСТЫ: диалоги, мини-игры, концовки, достижения — правь здесь
style.css
assets/sprites        спрайты 64×64 (вниз/влево/вправо/вверх)
assets/portraits      портреты 256×256
assets/cut.py         нарезка сгенерированных листов спрайтов и портретов
sw.js                 офлайн-кэш (меняй VERSION при каждом обновлении!)
manifest.webmanifest  установка на телефон
```

Сохранение — `localStorage`: `pg2_save` (текущая игра) и `pg2_meta` (память между прохождениями, достижения, блокировка). Режим `index.html?test` — игровой цикл на таймере для автотестов, объект `window.PG` — для отладки.

Первая, текстовая версия игры (v1) — в истории git.
